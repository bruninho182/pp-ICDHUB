Extensão para Google Chrome · Uso interno da Ingresso com Desconto
📅 Última atualização: 11 de agosto de 2026

1. Introdução

O ICD Hub é uma extensão para Google Chrome desenvolvida exclusivamente para uso interno da Ingresso com Desconto. Esta Política de Privacidade descreve como coletamos, usamos, armazenamos e protegemos as informações dos usuários da extensão, em conformidade com as políticas da Chrome Web Store e com a Lei Geral de Proteção de Dados (LGPD).

Ao utilizar o ICD Hub, você concorda com os termos descritos neste documento. Se você não concordar com esta política, recomendamos que não utilize a extensão.

2. Dados Coletados

A extensão coleta apenas os dados estritamente necessários para o cumprimento de sua finalidade operacional. Os dados coletados são:

  • Atividade do Usuário: Cliques, movimentos do mouse, preenchimento de formulários e tempo de inatividade. Esses dados são utilizados exclusivamente para o funcionamento do Dashboard de Desempenho e do sistema de Alertas Inteligentes, que notificam gestores sobre inatividade prolongada dos operadores.
  • Conteúdo do Site: Textos, imagens, dados de vouchers e informações de plataformas de turismo (TourCMS, Headout, GetYourGuide, Civitatis, TicketGO), acessados e processados localmente para executar automações como preenchimento de formulários, geração de vouchers, envio de e-mails e sincronização entre plataformas.

Não coletamos: Informações de identificação pessoal (nome, e-mail, CPF), dados de saúde, informações financeiras, senhas, dados de localização, histórico de navegação ou comunicações pessoais fora do escopo operacional.

3. Finalidade do Uso dos Dados

Os dados coletados são utilizados exclusivamente para:

  • Automatizar tarefas operacionais: Preenchimento automático de e-mails, geração e envio de vouchers, sincronização de dados entre plataformas de turismo, cálculos de orçamento e envio de mensagens padronizadas via WhatsApp.
  • Monitorar a produtividade da equipe: Através do Dashboard em tempo real, que exibe métricas como número de atendimentos, e-mails enviados, vouchers emitidos e tempo de atividade dos operadores.
  • Melhorar a eficiência operacional: Fornecendo alertas de inatividade e relatórios que auxiliam os gestores na tomada de decisões.

Todos os dados são processados localmente no dispositivo do usuário ou armazenados em servidores seguros da Supabase, com criptografia e acesso restrito aos administradores autorizados da Ingresso com Desconto.

4. Armazenamento e Segurança

  • Armazenamento local: Dados de configuração e preferências (mensagens prontas, atalhos, tarifários) são armazenados localmente no dispositivo do usuário via chrome.storage, garantindo persistência entre sessões sem necessidade de reconfiguração.
  • Armazenamento em nuvem: Métricas de desempenho (número de atendimentos, e-mails, vouchers, tempo de atividade) são enviadas para o banco de dados Supabase, que utiliza criptografia em trânsito e em repouso, com acesso restrito a administradores autorizados.
  • Medidas de segurança: Implementamos autenticação via login protegido, sessão persistente e controle de permissões por operador para garantir que apenas usuários autorizados acessem os dados.
  • Retenção de dados: Os dados são mantidos apenas pelo tempo necessário para cumprir as finalidades operacionais. Dados históricos podem ser retidos para análise de desempenho, mas sempre de forma agregada e anonimizada.

5. Compartilhamento de Dados

Não compartilhamos, vendemos ou transferimos dados dos usuários para terceiros. Os dados são utilizados exclusivamente para os fins operacionais descritos nesta política. Excepcionalmente, dados agregados e anonimizados podem ser utilizados para relatórios internos de desempenho, sem identificação individual dos operadores.

Compromisso: A Ingresso com Desconto não utiliza dados para fins de crédito, avaliação de credibilidade, marketing direcionado ou qualquer outra finalidade não relacionada à operação interna da extensão.

6. Direitos do Usuário

Os usuários do ICD Hub têm os seguintes direitos, em conformidade com a LGPD:

  • Acesso: Solicitar acesso aos dados armazenados sobre você.
  • Correção: Solicitar a correção de dados incompletos, inexatos ou desatualizados.
  • Exclusão: Solicitar a exclusão de seus dados pessoais, exceto quando a manutenção for necessária para cumprimento de obrigação legal ou regulatória.
  • Revogação de consentimento: A qualquer momento, você pode desinstalar a extensão e revogar seu consentimento para coleta de dados.

Para exercer esses direitos, entre em contato através dos canais informados na seção Contato abaixo.

7. Alterações nesta Política

Podemos atualizar esta política periodicamente para refletir mudanças em nossas práticas ou em requisitos legais. Notificaremos os usuários sobre mudanças significativas através da extensão (via notificação) ou por e-mail (caso tenhamos um endereço registrado). A data da última atualização será sempre exibida no topo desta página.

8. Declarações de Conformidade

Em conformidade com as políticas da Chrome Web Store, declaramos que:

  • Não vendemos nem transferimos dados do usuário a terceiros fora dos casos de uso aprovados.
  • Não usamos nem transferimos dados do usuário para fins não relacionados ao único objetivo da extensão.
  • Não usamos nem transferimos dados do usuário para determinar credibilidade ou para fins de empréstimo.
